# Note Component

A versatile note component for Angular applications that supports multiple visual variants and optional titles.

## Features

- 🎨 Multiple visual variants
- 📝 Optional title support
- 🎯 Semantic structure
- ♿ Accessibility support
- 💅 Tailwind CSS styling
- 📱 Responsive design
- 📖 Rich text formatting

## Usage
<Note
  title="Optional Title"
  text="Your note content here"
  variant="default"
/>


## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `text` | `string` | Required | Main note content |
| `title` | `string` | `undefined` | Optional note title |
| `variant` | `'default' \| 'muted' \| 'highlight'` | `'default'` | Visual style variant |

## Variants

### Default
- Gray theme
- Colors:
  - Background: `bg-gray-50`
  - Border: `border-gray-200`
  - Text: `text-gray-800`

### Muted
- White theme
- Colors:
  - Background: `bg-white`
  - Border: `border-gray-100`
  - Text: `text-gray-500`

### Highlight
- Yellow theme
- Colors:
  - Background: `bg-yellow-50`
  - Border: `border-yellow-200`
  - Text: `text-yellow-800`

### Container

The component implements several accessibility features:

- Semantic HTML structure
- Role="note" for screen readers
- ARIA labels combining title and text
- High contrast color combinations
- Clear visual hierarchy
- Proper heading structure
