# LastRefreshed Component

A dynamic timestamp component for Angular applications that displays when data was last updated, with support for both relative and absolute time formats.

## Features

- ⏰ Real-time relative time updates
- 📅 Absolute date-time formatting
- 🔄 Auto-updating display
- 🌍 Internationalization support
- 🎨 Customizable styling
- 🖼️ Optional clock icon
- ♿ Accessibility support

## Usage


<LastRefreshed
  lastUpdated='2025-05-26T06:19:18.779Z'
  label="Last updated"
  format="relative"
/>


## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `lastUpdated` | `Date \| string` | Required | Timestamp of last update |
| `label` | `string` | `'Last updated'` | Custom label text |
| `icon` | `boolean` | `true` | Show/hide clock icon |
| `format` | `'relative' \| 'absolute'` | `'relative'` | Time display format |

## Time Formats

### Relative Format (Default)
- "just now" (< 1 minute)
- "X minutes ago" (< 1 hour)
- "X hours ago" (< 24 hours)
- "X days ago" (< 7 days)
- Absolute date after 7 days

### Absolute Format
- Displays as "MMM D, YYYY, h:mm AM/PM"
- Example: "Jan 1, 2024, 2:30 PM"

## Examples

### Basic Usage with Relative Time
<LastRefreshed lastUpdated='2025-05-26T06:19:18.779Z' />


### Absolute Time Format

<LastRefreshed
  lastUpdated='2025-05-26T06:19:18.779Z'

/>


### Custom Label without Icon

<LastRefreshed
  lastUpdated='2025-05-26T06:19:18.779Z'
  label="Data refreshed"
  icon={false}
/>


### With String Date Input

<LastRefreshed
  lastUpdated="2024-01-01T12:00:00Z"
/>


## Auto-updating Behavior

- Relative timestamps automatically update every minute
- Updates continue until component is destroyed
- Automatic cleanup on component destruction
- Only active when using relative format

- Short month format
- Numeric day

- Minutes precision

## Best Practices

1. Choose appropriate format based on context:
   - Use relative for recent updates
   - Use absolute for historical data

2. Consider auto-refresh requirements:
   - Relative format updates automatically
   - Absolute format is static

3. Performance considerations:
   - Component cleans up its own intervals
   - Efficient update mechanism
   - Minimal DOM updates

4. Accessibility:
   - Keep labels clear and concise
   - Maintain proper contrast
   - Provide complete information via ARIA
