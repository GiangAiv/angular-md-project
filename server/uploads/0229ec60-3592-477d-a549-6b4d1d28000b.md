# ButtonGroup Component

A flexible button group component that allows users to select from multiple options. Perfect for toggles, filters, and segmented controls with a modern, accessible design.

## Features

- Multiple size options (small, medium, large)
- Optional rounded corners
- Full-width responsive grid layout option
- Accessible keyboard navigation
- Focus and hover states
- Supports both simple strings and complex options
- Responsive design
- Modern styling with Tailwind CSS

## Props

```tsx
interface ButtonOption {
  label: string;    // Display text for the button
  value: string;    // Value associated with the button
}

interface ButtonGroupProps {
  options: (string | ButtonOption)[];  // Required: Array of options (strings or ButtonOption objects)
  selected?: string;                   // Optional: Currently selected value
  size?: 'sm' | 'md' | 'lg';          // Optional: Button size (default: 'md')
  rounded?: boolean;                   // Optional: Use rounded corners (default: true)
  fullWidth?: boolean;                 // Optional: Use full width layout (default: false)
  selectionChange?: (value: string) => void; // Optional: Selection change handler
}
```

## Usage Examples

### Basic String Options
<ButtonGroup 
  options={['Daily', 'Weekly', 'Monthly']}
  selected="Weekly"
/>


### Complex Options with Labels
<ButtonGroup 
  options={[
  { label: '24h', value: 'daily' },
  { label: '7d', value: 'weekly' },
  { label: '30d', value: 'monthly' }
]}
  selected="weekly"
  size="sm"
/>


### Full Width Layout
<ButtonGroup 
  options={['Draft', 'In Review', 'Published', 'Archived']}
  fullWidth={true}
  rounded={false}
  size="lg"
/>


### Mixed Option Types
<ButtonGroup 
  options={[
  'Simple',
  { label: 'Complex', value: 'complex' },
  'Mixed'
]}
  selected="complex"
/>


## Styling

The component includes comprehensive built-in styling:

### Container
- Inline flex layout for default mode
- Responsive grid for full-width mode
- Proper spacing between buttons
- Relative positioning for proper stacking

### Buttons
- Three size variants:
  - Small: `px-2 py-1 text-xs`
  - Medium: `px-3 py-1.5 text-sm` (default)
  - Large: `px-4 py-2 text-base`
- State-based styling:
  - Selected: Blue background with white text
  - Unselected: White background with gray text
  - Hover: Darker background
  - Focus: Blue ring with offset
- Smooth transitions
- Optional rounded corners
- Consistent border treatment

## Layout Modes

### Inline Layout (Default)
- Horizontal button arrangement
- Fixed button width based on content
- Small gap between buttons
- Suitable for toolbar-style usage

### Full Width Layout
- Responsive grid layout
- 1 column on mobile
- 2 columns on tablet
- 3 columns on desktop
- Equal width buttons
- Gap between rows and columns

## Accessibility

The component implements several accessibility features:
- Proper role attributes (`role="group"`)
- ARIA labels for the group
- ARIA pressed state for buttons
- Keyboard focus management
- High contrast states
- Screen reader friendly structure

## State Management

The component handles state in the following ways:
- Tracks selected value internally
- Emits changes via `selectionChange` event
- Maintains selection state across re-renders
- Handles both controlled and uncontrolled usage

## Notes

- The component uses CommonModule for core directives
- Supports both simple and complex option types
- All buttons are type="button" to prevent form submission
- Focus ring is visible only on keyboard navigation
- Transitions are applied to colors only for performance
- Grid layout automatically adjusts based on screen size
- Selection state is preserved when options change
- All styling is customizable through props
