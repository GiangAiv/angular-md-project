
## Props

```tsx
interface DateRangeProps {
  startDate?: Date | string;  // Optional: Start date of the range
  endDate?: Date | string;    // Optional: End date of the range
  minDate?: Date;            // Optional: Minimum selectable date
  maxDate?: Date;            // Optional: Maximum selectable date
  placeholder?: string;      // Optional: Placeholder text
  disabled?: boolean;        // Optional: Disabled state
  label?: string;

  showPresets?: boolean;
  presetLabel?: string;
  defaultPreset?: string;
  presetRanges?: DateRangePresetOption[];
}
```

## Usage Examples

### Basic Usage - with title


<DateRange 
  label="Date Range"
  placeholder="Select date range..."
/>



### With Initial Dates
<DateRange 
  startDate='2024-01-01'
  endDate='2024-12-31'
/>

### With Date Restrictions

<DateRange 
  minDate={'2025-01-01'}
  maxDate={'2026-01-01'}
  placeholder="Select dates within next year"
/>


### Disabled State

<DateRange 
  startDate={'2024-01-01'}
  endDate={'2024-12-31'}
  disabled={true}
/>


### Customizing Multiple Preset Ranges + Default Preset

<DateRange 
  label="Custom Presets"
  showPresets={true}
  presetLabel="Select a range"
  defaultPreset="last-30-days"
  presetRanges={[
    { label: 'Last Week', value: 'last-7-days' },
    { label: 'Last Month', value: 'last-30-days' },
    { label: 'Last Quarter', value: 'last-90-days' },
    { label: 'This Year', value: 'year-to-date' }
  ]}
/>
